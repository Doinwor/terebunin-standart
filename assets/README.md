# Изображения для сайта

Файлы в этой папке подхватываются автоматически:

| Файл | Что это | Статус |
|---|---|---|
| `logo.png` | Логотип (эмблема с кабанами и фруктами) | ✔ есть |
| `qr.png` | QR-код для сбора вкладов | ✔ есть |
| `factory.png` | Фото цеха | ✔ есть |
| `product-classic.png` | «Классика» | ✔ есть |
| `product-terebun.png` | «Теребунская настойка» | ✔ есть |
| `product-kabani.png` | Партнёрская линейка «Три кабана» | ✔ есть |
| `hero-bg.jpg` | Фон главного экрана (не используется в светлой теме) | опционально |
| `map.jpg` | Скриншот карты с адресом | опционально |
